# BankSystem
Консольна банківська система. Реалізовано SOLID, Repository Pattern, асинхронний JSON Persistence та Strategy Pattern для комісій.

## 📊 Лабораторні роботи
- **Лабораторна 35**: Базова бізнес-логіка, сервіси та збереження в JSON.
- **Лабораторна 36**: Автоматизоване тестування (28 тестів) та Quality Gate.
- **Лабораторна 37**: Фіналізація проєкту та звіти.

# Lab 35 — Оновлення

## Додано
- JSON persistence для збереження даних у файл.
- Асинхронні операції з файлом (`SaveAsync` / `LoadAsync`).
- Strategy Pattern для комісій (`IFeeStrategy`, `StandardFeeStrategy`, `PremiumFeeStrategy`).
- LINQ-запити для аналітики та звітів.
- Покращену бізнес-логіку переказів та валідації.
