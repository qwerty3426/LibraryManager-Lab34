# TESTING — BankSystem

## Загальна інформація

Для перевірки коректності роботи системи використовуються unit-тести.

Тестування дозволяє:
- перевіряти бізнес-логіку;
- знаходити помилки;
- гарантувати стабільність системи.

---

# Основні перевірки

## Перекази

Перевіряється:
- успішний переказ;
- недостатній баланс;
- неіснуючі рахунки.

---

## Валідація

Перевіряється:
- сума > 0;
- унікальність IBAN;
- ліміти операцій.

---

## Persistence

Перевіряється:
- збереження JSON;
- завантаження JSON;
- коректність даних.

---

## Комісії

Перевіряється:
- StandardFeeStrategy;
- PremiumFeeStrategy;
- правильність обчислень.

---

# Unit Testing Framework

Використовується:
- xUnit / MSTest
