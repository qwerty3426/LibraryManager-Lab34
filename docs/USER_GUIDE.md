# USER GUIDE — BankSystem

# 1. Призначення системи

BankSystem — консольний застосунок для базового управління банківськими акаунтами.

Система дозволяє:
- створювати акаунти;
- поповнювати баланс;
- знімати кошти;
- переглядати список акаунтів;
- зберігати дані у JSON;
- відновлювати дані після перезапуску.

---

# 2. Запуск застосунку

У корені проєкту виконайте:

```bash
dotnet run --project src/BankSystem.Console
```

---

# 3. Основний сценарій роботи

## Створення акаунта

Користувач вводить:
- ім’я власника;
- початковий баланс.

Після цього система створює новий акаунт.

---

## Поповнення балансу

Користувач:
- обирає акаунт;
- вводить суму поповнення.

Система оновлює баланс.

---

## Зняття коштів

Користувач:
- обирає акаунт;
- вводить суму зняття.

Система:
- перевіряє достатність коштів;
- застосовує fee strategy;
- оновлює баланс.

---

# 4. Збереження даних

Усі акаунти автоматично зберігаються у JSON-файл.

Після повторного запуску:
- система завантажує попередні дані;
- відновлює стан акаунтів.

---

# 5. Обробка помилок

Система підтримує:
- перевірку некоректних сум;
- захист від від’ємного балансу;
- перевірку пошкодженого JSON;
- обробку пустих файлів.

---

Запуск усіх тестів:

