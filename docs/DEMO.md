# Demo Scenario

## Кроки для демонстрації

1. Запустіть додаток:
   ```bash
dotnet run --project src/BankSystem.Console
   ```
2. Створіть перший рахунок.
3. Проведіть депозит на рахунок.
4. Зніміть частину коштів.
5. Створіть другий рахунок.
6. Зробіть переказ між рахунками.
7. Перевірте список всіх рахунків.
8. Закрийте додаток.

## Показати під час захисту

- Архітектуру проекту;
- бізнес-логіку `BankService`;
- репозиторій `InMemoryRepository`;
- тестовий набір у `tests/BankSystem.Tests`;
- CI workflow в `.github/workflows`.
