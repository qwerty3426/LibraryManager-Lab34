# Vision — BankSystem

## Мета Lab 34
Створити просту консольну систему управління банківськими рахунками.

## Основна ідея
Проєкт демонструє базові принципи багатошарової архітектури з простими операціями над рахунками.

## Ключові можливості
- створення рахунків;
- депозит коштів;
- зняття коштів;
- переказ між рахунками;
- перегляд усіх рахунків.

## Обмеження Lab 34
- немає JSON persistence;
- немає Strategy Pattern;
- немає LINQ-аналітики;
- немає розширеного fault handling.

- доменні правила;
- інтерфейси.

## Application
Містить:
- бізнес-логіку;
- сервіси;
- перевірки.

## Infrastructure
Містить:
- роботу з JSON;
- persistence layer;
- репозиторії.

## Console
Містить:
- консольний інтерфейс;
- меню;
- взаємодію з користувачем.

---

# Persistence Layer

Для збереження даних використовуються:
- accounts.json
- transactions.json

Система автоматично:
- завантажує дані при старті;
- зберігає зміни після операцій.

---

# Strategy Pattern

Для розрахунку комісії використовується Strategy Pattern.

Реалізовано:
- StandardFeeStrategy
- PremiumFeeStrategy

Це дозволяє:
- легко додавати нові тарифи;
- не змінювати основну логіку системи.

---

# LINQ

У системі використовуються LINQ-запити для:
- пошуку;
- сортування;
- групування;
- агрегації даних.
