# TESTING.md

## Запуск тестів

Запустити всі тести:

```bash
dotnet test
```

---

## Запуск тестів із coverage

```bash
dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=opencover
```

---

## Що перевіряють тести

### Unit-тести
- створення акаунта
- зняття коштів
- перевірка балансу
- обчислення комісії
- обробка винятків

### Інтеграційні тести
- запис у JSON
- читання JSON
- обробка пошкодженого JSON
- робота з тимчасовими файлами

### Негативні сценарії
- неіснуючий акаунт
- недостатньо коштів
- помилки доступу до файлів
