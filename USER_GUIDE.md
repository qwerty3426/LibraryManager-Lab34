# User Guide

## BankSystem v1.0.0 Release Candidate

BankSystem — консольна програма для управління простими банківськими рахунками.

## Як користуватися

1. Запустіть програму:
   ```bash
dotnet run --project src/BankSystem.Console
   ```
2. Виберіть дію з меню:
   - 1 — створити рахунок;
   - 2 — внести депозит;
   - 3 — зняти кошти;
   - 4 — переказати кошти;
   - 5 — показати всі рахунки;
   - 0 — вихід.
3. Введіть потрібні дані та підтвердіть.

## Підказки

- Використовуйте коректні числові значення для балансу та сум.
- Значення має бути більше за нуль.
- Переконайтеся, що у відправника достатньо коштів для переказу.

## Обмеження версії

- Дані зберігаються тільки під час виконання програми;
- немає інтеграції з зовнішньою базою даних;
- інтерфейс — консольний.
