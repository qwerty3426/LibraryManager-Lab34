# План релізу — v1.0.0

## Функціональність, що входить у версію v1.0.0

- створення банківських акаунтів;
- операції поповнення та зняття коштів;
- валідація транзакцій;
- JSON persistence;
- Generic Repository Pattern;
- Strategy Pattern для комісій;
- LINQ-запити;
- unit tests;
- integration tests;
- генерація coverage report.

---

## Покращення після завершення курсу

Функціональність, яку можна додати після курсу:

- підтримка бази даних;
- система авторизації;
- UI для історії транзакцій;
- ASP.NET frontend;
- асинхронні операції.

---

## Допустимий технічний борг

Для версії v1.0.0 допустимими є:

- консольний інтерфейс;
- відсутність повноцінної СУБД;
- базове логування;
- відсутність DI-контейнера.
