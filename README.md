# BankSystem 

BankSystem — консольна банківська система, розроблена в рамках лабораторних робіт з дисципліни «Об’єктно-орієнтоване програмування».

---

## 📊 Структура Лабораторних Робіт

### 🔹 Лабораторна робота №35 (Business & Persistence)
- Реалізовано доменну логіку банку (BankService).
- Асинхронне збереження даних у JSON-файли.
- Стратегії обчислення комісій (StandardFeeStrategy, PremiumFeeStrategy).
- Аналітичні LINQ-запити.

### 🔹 Лабораторна робота №36 (Quality Gate)
- Налаштовано контроль якості та автоматизоване тестування.
- Створено тестову стратегію та матрицю тестування.

### 🔹 Лабораторна робота №37 (Фінальний Етап)
- Розширення функціоналу та фіналізація проєкту.
