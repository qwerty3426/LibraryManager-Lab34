# Стратегія тестування

## Мета тестування

Перевірити правильність та стабільність роботи банківської системи.

---

## Критичні сценарії

- створення акаунта
- зняття коштів
- обчислення комісії
- збереження у JSON
- завантаження з JSON
- обробка помилок

---

## Unit-тести

Unit-тести перевіряють:
- BankService
- StandardFeeStrategy
- PremiumFeeStrategy

---

## Інтеграційні тести

Інтеграційні тести перевіряють:
- реальну роботу з файлами
- JSON serialization
- JSON deserialization
- persistence

---

## Обробка помилок

Система повинна правильно обробляти:
- неіснуючі акаунти
- недостатній баланс
- пошкоджені JSON-файли
- помилки доступу до файлів
